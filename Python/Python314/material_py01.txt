Section 1.2: Variables and Data Types
In Python, variables serve as named containers for storing various types of information. Data types categorize the kind of information a variable holds, influencing how that data can be manipulated.

What are Variables?
A variable is a symbolic name that refers to a storage location in the computer's memory. This location holds a value, and the value associated with a variable can be changed during the execution of a program.

How to Create a Variable:
You create a variable by simply assigning a value to a chosen name using the assignment operator (=).

# Creating variables
my_number = 10          # An integer variable
my_text = "Hello, Python!" # A string variable
is_active = True        # A boolean variable

Common Data Types:
int (Integer):
Represents whole numbers, which can be positive, negative, or zero, without any fractional components.

age = 30
quantity = -5

float (Floating-point number):
Represents real numbers, which include a decimal point.

price = 19.99
temperature = 25.5

str (String):
Represents sequences of characters. Strings are immutable (cannot be changed after creation) and are typically enclosed in either single quotes (' ') or double quotes (" ").

name = "Alice"
message = 'Welcome to the course!'

String Operations:

greeting = "Hello"
name = "Bob"
full_message = greeting + ", " + name + "!" # Concatenation: joining strings
print(full_message) # Output: Hello, Bob!

print(len(full_message)) # Returns the length (number of characters) of the string
print(name[0]) # Accessing characters by index (0-based indexing): retrieves the first character
print(name[1:3]) # Slicing: retrieves characters from index 1 up to (but not including) index 3

list (List):
Represents ordered, mutable (changeable) collections of items. List items can be of different data types and are defined using square brackets ([]).

fruits = ["apple", "banana", "cherry"]
numbers = [1, 2, 3, 4, 5]
mixed_list = [1, "hello", True, 3.14]

List Operations:

fruits.append("orange") # Adds an item to the end of the list
print(fruits) # Output: ['apple', 'banana', 'cherry', 'orange']
fruits.remove("banana") # Removes the first occurrence of a specified item
print(fruits) # Output: ['apple', 'cherry', 'orange']
print(fruits[0]) # Accessing by index: retrieves the item at the specified index (first item)
print(len(fruits)) # Returns the number of items in the list

tuple (Tuple):
Represents ordered, immutable (unchangeable) collections of items. Tuples are defined using parentheses (()).

coordinates = (10.0, 20.0)
colors = ("red", "green", "blue")

Tuples are generally faster than lists and are preferred when the data collection should not be modified after its creation.

dict (Dictionary):
Represents unordered, mutable collections of key-value pairs. Each key within a dictionary must be unique. Dictionaries are defined using curly braces ({}).

person = {"name": "John Doe", "age": 25, "city": "New York"}

Dictionary Operations:

print(person["name"]) # Accessing a value by its corresponding key
person["age"] = 26 # Modifying the value associated with an existing key
person["occupation"] = "Engineer" # Adding a new key-value pair to the dictionary
print(person) # Output: {'name': 'John Doe', 'age': 26, 'city': 'New York', 'occupation': 'Engineer'}

set (Set):
Represents unordered, mutable collections of unique items. Duplicate elements are automatically discarded. Sets are defined using curly braces ({}) or by using the set() constructor.

unique_numbers = {1, 2, 3, 2, 1} # Duplicates (2 and 1) are automatically removed
print(unique_numbers) # Output: {1, 2, 3}

Sets are particularly useful for checking membership, efficiently removing duplicate entries from a collection, and performing mathematical set operations (such as union, intersection, and difference).

Checking Data Type:
You can determine the data type of any variable using the built-in type() function:

Section 1.3: Control Structures
Control structures are fundamental programming constructs that determine the order in which instructions are executed. They allow your program to make decisions or perform repetitive tasks based on specified conditions.

1. if-else Statements (Conditional Execution)
if-else statements are used to execute different blocks of code depending on whether a given condition evaluates to True or False.

# Basic if statement
score = 85
if score >= 70:
    print("You passed!") # This line will be printed because the condition (85 >= 70) is True

# if-else statement
temperature = 15
if temperature > 25:
    print("It's hot!")
else:
    print("It's not too hot.") # This line will be printed because the condition (15 > 25) is False

# if-elif-else statement (elif is short for "else if")
grade = 75
if grade >= 90:
    print("A")
elif grade >= 80: # This condition is checked only if the previous 'if' condition was False
    print("B")
elif grade >= 70: # This condition is checked only if the previous 'elif' condition was False
    print("C") # This line will be printed
else: # This block executes if none of the above conditions were True
    print("Fail")

Important Note on Indentation: Python uses indentation (consistent spaces or tabs) to define code blocks, unlike many other programming languages that use curly braces {}. Maintaining consistent indentation is absolutely critical for correct program execution in Python.

2. Loops (Repetitive Execution)
Loops are used to execute a block of code multiple times.

for loop:
The for loop is used for iterating over a sequence (such as a list, tuple, string, or range of numbers). It executes the code block once for each item in the sequence.

# Iterating over a list
fruits = ["apple", "banana", "cherry"]
for fruit in fruits:
    print(fruit)
# Expected Output:
# apple
# banana
# cherry

# Using range() for a specific number of iterations
# range(5) generates a sequence of numbers: 0, 1, 2, 3, 4
for i in range(5):
    print(i)
# Expected Output:
# 0
# 1
# 2
# 3
# 4

# Looping through characters in a string
my_string = "Python"
for char in my_string:
    print(char)
# Expected Output:
# P
# y
# t
# h
# o
# n

while loop:
The while loop repeatedly executes a block of code as long as a specified condition remains True. It's crucial to ensure that the condition eventually becomes False to prevent an infinite loop.

count = 0
while count < 3: # The loop continues as long as 'count' is less than 3
    print("Count is:", count)
    count += 1 # Increment 'count' by 1 (shorthand for: count = count + 1)
# Expected Output:
# Count is: 0
# Count is: 1
# Count is: 2

Loop Control Statements:
These statements allow you to alter the normal flow of a loop.

break:
The break statement immediately terminates the innermost loop it is contained within. Program execution then continues with the statement immediately following the loop.

for i in range(10):
    if i == 5:
        break # Loop terminates when i becomes 5
    print(i)
# Expected Output: 0, 1, 2, 3, 4

continue:
The continue statement skips the rest of the current iteration of the loop and proceeds to the next iteration.

for i in range(5):
    if i == 2:
        continue # Skips the print statement for i = 2
    print(i)
# Expected Output: 0, 1, 3, 4

Section 1.4: Functions, Lambda Functions, and Scope
Functions are fundamental building blocks in programming that allow you to encapsulate reusable blocks of code, improving organization, readability, and maintainability of your programs.

What are Functions?
Organization: Functions help break down complex problems into smaller, manageable pieces.

Reusability: Once defined, a function can be called multiple times from different parts of your program, avoiding code duplication.

Readability: Functions give meaningful names to blocks of code, making the program easier to understand.

Functions are defined using the def keyword, followed by the function name, parentheses (which may contain arguments), and a colon.

They can optionally take arguments (inputs) and can return a value (output) using the return keyword.

# Defining a simple function that prints a message
def greet():
    print("Hello there!")

# Calling the function to execute its code
greet() # Output: Hello there!

# Function with arguments (parameters)
# 'name' is an argument that the function expects to receive
def greet_name(name):
    # f-string (formatted string literal) is a convenient way to embed expressions inside string literals
    print(f"Hello, {name}!")

greet_name("Alice") # Output: Hello, Alice!
greet_name("Bob") # Output: Hello, Bob!

# Function with a return value
# This function calculates the sum of two numbers and returns the result
def add_numbers(a, b):
    result = a + b
    return result # The 'return' statement sends the 'result' back to where the function was called

sum_result = add_numbers(5, 3) # The returned value (8) is stored in 'sum_result'
print(sum_result) # Output: 8

Lambda Functions (Anonymous Functions):
Lambda functions are small, anonymous (meaning they don't have a formal def name) functions.

They are defined using the lambda keyword.

A lambda function can take any number of arguments but can only have one expression. The result of this expression is implicitly returned.

They are often used for short, simple, single-expression functions, particularly when passed as arguments to higher-order functions (functions that take other functions as arguments).

# Regular function equivalent
def multiply_by_two(x):
    return x * 2

# Equivalent lambda function
multiply_lambda = lambda x: x * 2

print(multiply_by_two(5)) # Output: 10
print(multiply_lambda(5)) # Output: 10

# Lambda used with a higher-order function (e.g., list's sort method)
points = [{"x": 2, "y": 5}, {"x": 1, "y": 8}, {"x": 3, "y": 2}]
# Sort the list of dictionaries based on their 'y' value
# 'key=lambda p: p["y"]' tells the sort method to use the 'y' value of each dictionary for comparison
points.sort(key=lambda p: p["y"])
print(points) # Output: [{'x': 3, 'y': 2}, {'x': 2, 'y': 5}, {'x': 1, 'y': 8}]

Scope:
Scope refers to the region within a program where a variable is accessible (can be referenced or modified). Understanding scope is crucial to avoid unexpected behavior in your code.

Local Scope:
Variables defined inside a function are said to have local scope. They can only be accessed and used within that specific function. Once the function finishes execution, these local variables cease to exist.

Global Scope:
Variables defined outside of any function (at the top level of a script) have global scope. They can be accessed from anywhere in the program, both inside and outside functions.

global_var = "I am global" # This variable has global scope

def my_function():
    local_var = "I am local" # This variable has local scope (to my_function)
    print(global_var) # A function can access global variables
    print(local_var) # A function can access its own local variables

my_function() # Call the function to execute its code
print(global_var) # The global variable is accessible here
# print(local_var) # This line would cause a NameError because 'local_var' is not defined in the global scope

Best Practice: While you can access global variables from within a function, it's generally considered good practice to pass data into functions via arguments and return results. This makes your functions more self-contained, easier to test, and less prone to side effects, leading to more understandable and debuggable code.

Section 1.5: Exception Handling
Exception handling is a critical programming concept that allows your program to gracefully manage and respond to errors (known as "exceptions") that occur during its execution. Instead of crashing, your program can "catch" these errors and execute alternative code, making it more robust and user-friendly.

try-except Block:
The primary construct for exception handling in Python is the try-except block.

The code that you anticipate might cause an error is placed inside the try block.

If an error (exception) occurs within the try block, the normal execution flow is interrupted, and Python looks for a matching except block.

If a matching except block is found, the code within that except block is executed.

If no exception occurs in the try block, the except block(s) are skipped.

An optional finally block can be included, which always executes, regardless of whether an exception occurred or was handled.

try:
    # This line attempts a division by zero, which will raise a ZeroDivisionError
    result = 10 / 0
    print(result) # This line will not be reached if an error occurs above
except ZeroDivisionError:
    # This block executes specifically if a ZeroDivisionError occurs
    print("Error: Cannot divide by zero!")
except TypeError:
    # You can include multiple except blocks to handle different types of errors
    print("Error: Type mismatch! Please check your input types.")
except Exception as e: # This is a general exception handler
    # 'Exception' is the base class for most built-in exceptions.
    # 'as e' captures the exception object, allowing you to print its message.
    print(f"An unexpected error occurred: {e}")
finally:
    # The 'finally' block always executes, whether an exception occurred or not,
    # and whether it was handled or not. It's often used for cleanup operations.
    print("This block always executes, regardless of errors.")

Common Built-in Exceptions:
Python has a rich hierarchy of built-in exceptions. Here are some commonly encountered ones:

ZeroDivisionError: Raised when an attempt is made to divide a number by zero.

TypeError: Raised when an operation or function is applied to an object of an inappropriate type (e.g., trying to add a number to a string without conversion).

NameError: Raised when a local or global name is not found (i.e., a variable or function is used before it's defined).

FileNotFoundError: Raised when an attempt to open a file (using open()) fails because the file does not exist.

IndexError: Raised when a sequence (like a list or tuple) index is out of range.

KeyError: Raised when a dictionary key is not found.

ValueError: Raised when an operation or function receives an argument that has the right type but an inappropriate value (e.g., int("hello")).

Section 1.7: File I/O (Input/Output)
File I/O (Input/Output) refers to the process of reading data from external files and writing data to them. This capability is fundamental for interacting with persistent data storage, allowing your programs to save information and retrieve it later.

Opening and Closing Files:
The open() function is used to establish a connection with a file. It takes the file path and a mode as arguments and returns a file object, which acts as an interface to the file.

It is crucial to close the file after you have finished reading from or writing to it. Closing a file releases the system resources it was using and ensures that any buffered writes are flushed to disk. The close() method of the file object performs this.

The with open(...) statement is the recommended way to handle file operations in Python. It creates a context manager that automatically ensures the file is properly closed, even if errors occur during file processing. This eliminates the need for explicit file.close() calls and is safer.

File Modes:
When opening a file, you specify a mode to indicate how you intend to interact with it:

"r": Read mode (default). Opens the file for reading. If the file does not exist, a FileNotFoundError will be raised.

"w": Write mode. Opens the file for writing. If the file already exists, its contents will be truncated (overwritten). If the file does not exist, a new empty file will be created.

"a": Append mode. Opens the file for appending. If the file exists, new content will be added to the end of the file. If the file does not exist, a new empty file will be created.

"x": Exclusive creation mode. Creates a new file. If the file already exists, a FileExistsError will be raised. This is useful to ensure you're not overwriting an existing file.

"t": Text mode (default). Used for reading and writing text. Data is handled as strings, with encoding/decoding performed automatically.

"b": Binary mode. Used for reading and writing binary data (e.g., images, executables). Data is handled as bytes.

Reading Text Files:
# First, let's create a sample text file named 'my_file.txt' for demonstration.
# You can manually create this file in the same directory as your Python script,

# Using the 'with' statement (highly recommended for automatic file closing)
print("--- Reading entire file content ---")

    content = file.read() # Reads the entire content of the file as a single string
    print(content)

    lines = file.readlines() # Reads all lines into a list of strings, including newline characters
    for line in lines:

print("\n--- Iterating line by line (memory efficient) ---")
with open("my_file.txt", "r") as file:
    for line in file: # This is often the most memory-efficient way to read large files
        print(line.strip())

Working with CSV Files:
CSV (Comma Separated Values) files are a common format for storing tabular data. Python's built-in csv module provides functionality for reading and writing CSVs. For more advanced data manipulation with CSVs, the pandas library (covered in Module 2) is typically used.

import csv

# Writing to a CSV file
print("--- Writing to a CSV file ---")
data = [
    ["Name", "Age", "City"],
    ["Alice", 30, "New York"],
    ["Bob", 24, "London"],
    ["Charlie", 35, "Paris"]
]

# 'newline=""' is crucial when writing CSVs to prevent extra blank rows
with open("people.csv", "w", newline="") as file:
    writer = csv.writer(file) # Creates a writer object
    writer.writerows(data) # Writes multiple rows from a list of lists
print("Data written to people.csv.")

# Reading from a CSV file
print("\n--- Reading from a CSV file (as lists of strings) ---")
with open("people.csv", "r") as file:
    reader = csv.reader(file) # Creates a reader object
    for row in reader:
        print(row)
# Expected Output:
# ['Name', 'Age', 'City']
# ['Alice', '30', 'New York']
# ['Bob', '24', 'London']
# ['Charlie', '35', 'Paris']

# Reading from a CSV file as dictionaries (more convenient for column-based access)
print("\n--- Reading from a CSV file (as dictionaries) ---")
with open("people.csv", "r") as file:
    reader = csv.DictReader(file) # The first row is automatically used as keys for dictionaries
    for row in reader:
        print(f"Name: {row['Name']}, Age: {row['Age']}")
# Expected Output:
# Name: Alice, Age: 30
# Name: Bob, Age: 24
# Name: Charlie, Age: 35
